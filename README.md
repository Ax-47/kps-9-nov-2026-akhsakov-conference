# แนะแนว Programming — เว็บ

เว็บแนะแนวรุ่นน้อง ม.ปลาย: ภาษาโปรแกรมแก้ปัญหาอะไรมาบ้าง (C → C++ → Go → Rust), เริ่มทำแอป เว็บ เกม,
สมองเรียนรู้ยังไง และซ้อมแข่งให้สมองจำได้จริง

เขียนด้วย HTML + CSS + JavaScript ล้วน ไม่มี framework ไม่มี library ไม่ต้อง build

ดูออนไลน์: https://ax-47.github.io/kps-9-nov-2026-akhsakov-conference/

## ลูกเล่น

- แนวโปสเตอร์คอมยุค Y2K: น้ำเงินไฟฟ้า + ขาว / เขียวนีออน / แดงเตือน, ตัวใหญ่บีบแคบ, หน้าต่าง OS, กล่องเตือน, จอฟ้า, กริด, เกรนฟิล์ม
- สีพื้นทั้งหน้าเปลี่ยนตามส่วนที่อ่านอยู่ (น้ำเงิน / ขาว / กรมท่า)
- หน้า **แนะนำตัว speaker** (`#speaker`) เป็นคอมพิวเตอร์สมจริง: จอขอบบางพร้อมขาตั้ง, เปิดเครื่องมีโลโก้กับวงหมุน, วอลเปเปอร์ท้องฟ้า-เนินหญ้าวาดเองด้วย SVG, หน้าต่างแอป profile / terminal whoami / กล่องข้อความ rules เด้งขึ้นทีละบาน ลาก ย่อ ขยาย ปิดได้, แถบงานพร้อมเมนู start ไอคอนระบบ นาฬิกาและวันที่, คลิกขวาบนเดสก์ท็อปมีเมนู (`desktop.js`) — ช่องกรอบเหลือง `[…]` (class `fill-me`) คือข้อมูลที่ต้องใส่เอง
- หัวข้อมีแอนิเมชัน: หัวข้อไทยมีแถบสีกวาดผ่าน, คำยักษ์ตัวอักษรลอยขึ้นทีละตัว, ป้ายเล็กพิมพ์ออกมาแบบเครื่องพิมพ์ดีด
- ไทม์ไลน์ประวัติภาษา **แบ่ง 4 ยุคชัด ๆ** (ERA 0 บุกเบิก · ERA 1 Structured · ERA 2 OOP · ERA 3 Composition) มีการ์ดคั่นยุคพร้อม BUG / FIX / COST และแถบยุคด้านบนที่กดกระโดดได้
- แต่ละ Part มีช่วงที่ **เลื่อนลงแล้วเนื้อหาเลื่อนไปด้านข้าง** (ไทม์ไลน์ภาษา, เส้นทางแต่ละสาย, เรื่อง HM, วงจรซ้อม)
  บนมือถือช่วงนี้กลายเป็นแถบปัดซ้าย-ขวา
- ตัวอักษรใหญ่วิ่งตามการเลื่อน, ของค่อย ๆ โผล่ตอนเลื่อนมาถึง
- **เกม HP BATTLE** ในเทอร์มินัลบนเว็บ (Misha & Nova vs SEGFAULT) พอร์ตจากโปรแกรม C ของโจทย์ระบบ HP วางคู่กับแท็บโค้ด: เลือก C / C + goto = hp ไม่มีเจ้าของ (ติดลบแต่ไม่ล้ม), เลือก Java / Go / Rust = hp มีเจ้าของ กฎครบ เล่นด้วย seed เดิมเทียบกันได้
- จับเวลาพัก 10 นาทีในจอฟ้า, แท็บเทียบโค้ดเกม HSR ใน C + goto / C / Java / Go / Rust
- เกมจำตัวเลข 10 วินาที (chunking), กราฟ forgetting curve, ควิซกดดูเฉลย
- ลูกเล่น (`fun.js`): ตัวเลขนับขึ้น, คำยักษ์สลับตัวอักษร, คลิกแล้วมีพิกเซลกระจาย, การ์ดเอียงตามเมาส์, ปุ่ม _ □ × ของหน้าต่างกดได้, แจ้งเตือนตอนเข้าแต่ละ Part และคำลับ `rust` `goto` `sleep` `sudo`
- ถ้าตั้งค่าลดการเคลื่อนไหว (prefers-reduced-motion) ลูกเล่นที่ขยับเองจะปิด

## เปิดดูในเครื่อง

```bash
python3 -m http.server 8000
```

แล้วเข้า http://localhost:8000

## โครงโปรเจกต์

```
index.html   เนื้อหาทั้งหมด
style.css    หน้าตา สีแต่ละส่วน และแถบเลื่อนด้านข้าง
game.js      เกม HP BATTLE (กฎ HP อยู่ในฟังก์ชัน isDown / takeDamage / heal ที่เดียว)
desktop.js   คอมพิวเตอร์ของหน้าแนะนำตัว (เปิดเครื่อง หน้าต่าง แถบงาน เมนู start คลิกขวา นาฬิกา)
fun.js       ลูกเล่นเสริม + แถบยุคของไทม์ไลน์
main.js      เปลี่ยนสีพื้น, เลื่อนด้านข้างตามการเลื่อนลง, ตัวอักษรวิ่ง, แท็บโค้ด, เกมจำตัวเลข
assets/      รูป (webp)
```

แก้เนื้อหาใน `index.html` ได้ตรง ๆ แต่ละส่วนเป็น `<section data-bg="blue|paper|ink" data-label="...">`
โดย `data-bg` คือสีพื้นตอนอ่านส่วนนั้น และ `data-label` คือข้อความที่แถบบนแสดง

ช่วงเลื่อนด้านข้าง คือ `<section class="hscroll">` ใส่ `<article class="panel">` เพิ่มใน `.hscroll-track` ได้เลย
ความยาวการเลื่อนคำนวณให้เอง

## Deploy

push ขึ้น `main` แล้ว `.github/workflows/pages.yml` จะอัปขึ้น GitHub Pages ให้เอง
(Settings → Pages → Source ต้องเป็น **GitHub Actions**)
