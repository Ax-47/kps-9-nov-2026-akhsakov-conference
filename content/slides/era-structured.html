BUG

FIX

for (int k = 0; k < 4; k++) {

จุดเริ่มของ structured programming

เปิดยุคที่ 1: ยุคเมนเฟรมกับ Structured programming (1960s–1970s ตามหัวข้อ “1960s and 1970s” ของ Wikipedia ส่วนคำว่า structured programming เริ่มดังจริงปี 1968) ปัญหา: พอโปรแกรมใหญ่ขึ้น โค้ดที่กระโดดด้วย GOTO พันกันจนอ่านไม่ออก แก้ตรงหนึ่งไปพังอีกตรง ปี 1968 ที่ประชุมวิศวกรรมซอฟต์แวร์ของ NATO ใช้คำว่า software crisis และปีเดียวกัน Dijkstra เขียนจดหมาย Go To Statement Considered Harmful ทางแก้: เขียนด้วยโครงสร้างแค่ 3 แบบ คือ ทำต่อกัน เลือก (if) และวนซ้ำ (loop) แล้วแตกงานเป็นฟังก์ชัน ภาษาตัวแทนคือ Pascal (1970) ที่ออกแบบมาสอนวิธีนี้ และ C (1972) ที่ใช้เขียน Unix โค้ดบนสติกเกอร์คือด่าน Honkai: Star Rail ตัวเดิมจากสไลด์ GOTO แต่เขียนแบบมีโครงสร้าง: วนทีละเหตุการณ์ ล้มเมื่อไหร่ก็ออกจากลูป ไม่ต้องไล่ลูกศรเลย (play เป็นฟังก์ชันสมมติที่ทำเหตุการณ์นั้น) ราคาที่จ่าย: ข้อมูลยังเป็นของกลาง ฟังก์ชันไหนก็แก้ได้ ซึ่งจะกลายเป็นปัญหาของยุค OOP สไลด์ถัดไป: ปัญหา GOTO ตัวจริงในเกม Honkai: Star Rail บริบทจาก Wikipedia: เมนเฟรมช่วงต้นยุค 60s ใช้ได้เฉพาะผู้เชี่ยวชาญ ป้อนโปรแกรมด้วยบัตรเจาะรู และโต้ตอบกับเครื่องระหว่างรันไม่ได้ ภาษายุคนั้นจึงออกแบบมาให้มีการโต้ตอบน้อยที่สุด พอยุค 70s คอมพิวเตอร์ถูกลง ภาษาก็เริ่มรองรับการโต้ตอบมากขึ้น ALGOL (1958, 1960) กลายเป็นมาตรฐานสำหรับเขียนอัลกอริทึม และเป็นต้นตระกูลของ C, Pascal, Ada, C++, Java และ C# (เลยเขียนว่า “ตระกูล ALGOL” ในแถว FIX) ยุคเดียวกันยังมีวิธีคิดแบบอื่นเกิดขึ้น ถ้ามีน้องถาม: Lisp (1958) ภาษา functional ภาษาแรก และมี garbage collection / Prolog (1972) ภาษา logic ภาษาแรก / ML (1978) ที่ compiler อนุมานชนิดข้อมูลให้เอง อ้างอิงลำดับยุค: Wikipedia — Programming language (หัวข้อ History)
