สายแอปมี 2 ทาง: • ข้ามแพลตฟอร์ม (Flutter, React Native) — เขียนครั้งเดียวได้ทั้ง Android และ iOS เหมาะกับมือใหม่และทีมเล็ก • Native (Kotlin, Swift) — ได้ประสิทธิภาพและฟีเจอร์ของระบบเต็มที่ แต่ต้องเขียนแยกสองชุด ฝั่ง iOS ต้องใช้ Mac ในการ build (นึกถึง Java ใน Part 1: “เขียนครั้งเดียว รันทุกที่” ก็คือไอเดียเดียวกับ Flutter/React Native เลย) โปรเจกต์ที่ 3 flashcard แบบเว้นระยะ — ทิ้งไว้เป็นปริศนา เดี๋ยว Part 3 จะเล่าว่าทำไมการทวนแบบเว้นระยะถึงได้ผล แล้วน้องจะอยากทำแอปนี้ใช้เอง
