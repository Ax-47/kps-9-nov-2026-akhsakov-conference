Paradigm ≠ ภาษา

Paradigm คือ “วิธีคิด” ไม่ใช่ตัวภาษา

Imperative

บอกคอม “ทีละขั้น” ว่าต้องทำอะไร เช่น procedural (C) และ OOP (Java)

total = 0
for x in xs:
    if x > 0:
        total += x * x

Declarative

บอกคอมว่า “อยากได้อะไร” เช่น functional (Haskell) และ SQL

total = sum(x * x
    for x in xs
    if x > 0)

ภาษาสมัยใหม่ส่วนใหญ่เป็น multi-paradigm — Python, Rust, JavaScript เขียนได้หลายแบบในภาษาเดียว

เคลียร์ความสับสนที่เจอบ่อย: paradigm ไม่ใช่ภาษา แต่เป็นวิธีคิดตอนเขียน Imperative = เหมือนบอกทางเพื่อนทีละเลี้ยว “เดินตรงไป เลี้ยวซ้าย ผ่านเซเว่นแล้วเลี้ยวขวา” Declarative = บอกแค่ปลายทาง “ไปเซ็นทรัล” แล้วให้คนขับ (หรือ Google Maps) หาทางเอง ตัวอย่างโค้ดทั้งสองฝั่งเป็น Python ทั้งคู่ และให้ผลเท่ากัน: ผลรวมกำลังสองของเลขที่มากกว่า 0 ฝั่งซ้ายบอกทีละขั้น ฝั่งขวาบรรยายว่าอยากได้อะไร นี่คือเหตุผลที่บอกว่า Python เป็น multi-paradigm SQL ที่น้องอาจเจอในวิชาฐานข้อมูลก็เป็น declarative: บอกว่าอยากได้ข้อมูลแบบไหน ไม่ได้บอกว่าต้องค้นยังไง Functional programming (เช่น Haskell) ส่งไอเดียอย่าง map, filter, ค่าที่แก้ไม่ได้ (immutable) ให้ภาษาอื่นเยอะมาก Rust ได้ไปเต็ม ๆ
