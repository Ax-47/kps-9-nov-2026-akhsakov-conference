สรุป Part 1

ทุกทางแก้ มีราคาที่ต้องจ่าย

ภาษาปีแก้ปัญหาอะไรจ่ายอะไรแลก
C1972เขียน OS ให้ย้ายเครื่องได้ดูแลหน่วยความจำเอง
C++1985ความเร็ว C + จัดโค้ดแบบ objectภาษาใหญ่ และซับซ้อน
Go2009compile เร็ว ทำงานพร้อมกันง่ายจงใจเรียบ ขาดบางฟีเจอร์
Rust2015เร็ว + ปลอดภัย โดยไม่มี GCเรียนยาก compile ช้า
สรุป Part 1 ด้วยตารางนี้ ชี้ให้เห็นว่าคอลัมน์ “จ่ายอะไรแลก” ของภาษาหนึ่ง มักกลายเป็น “แก้ปัญหาอะไร” ของภาษาถัดไป เช่น C ปล่อยให้ใครก็แก้ข้อมูลได้ → C++ แก้ด้วย class แต่ภาษาใหญ่ขึ้นและต้นไม้คลาสลึก → Go ตัดการสืบทอดทิ้ง ให้ภาษาเรียบ / C ต้องดูแลหน่วยความจำเอง → Rust แก้ด้วย ownership โดยไม่ต้องมี GC ถามน้อง 1 คำถาม: ถ้าจะทำเว็บเล็ก ๆ ส่งงานพรุ่งนี้ จะเลือกภาษาไหน? ถ้าจะเขียนเฟิร์มแวร์หุ่นยนต์ จะเลือกภาษาไหน? (ให้ตอบพร้อมเหตุผลจากตาราง)
