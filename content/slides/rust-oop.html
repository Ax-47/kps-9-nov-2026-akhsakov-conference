Polymorphism

ต้องเขียน impl Item for ... ให้ชัด แล้วใส่คลังไอเทมเดียวกันได้

pub struct Ally {
    hp: i32,  // ไม่มี pub = private
}
trait Item {
    fn use_on(&self, a: &mut Ally);
}
struct Food;
impl Item for Food {
    fn use_on(&self, a: &mut Ally) {
        a.heal(75);
    }
}
struct Health { hp: i32 }
struct Memosprite { health: Health }  // มี
for it in &inventory { it.use_on(&mut me); }

เกม Honkai: Star Rail ตัวเดิมฉบับ Rust วางคู่กับสไลด์ OOP แบบ Go ให้น้องเห็นว่า OOP สมัยใหม่ไม่ต้องมี class เลขในโค้ดตรงกับเลขด้านซ้าย 1) Encapsulation — Rust ซ่อนทุกอย่างไว้ก่อน ฟิลด์ที่ไม่ใส่ pub ใช้ได้แค่ใน module เดียวกัน ถ้าไฟล์อื่นเขียน me.hp = -70 จะ compile ไม่ผ่าน (error E0616: field `hp` ... is private) ต้องเรียกเมธอดใน impl Ally เช่น take_damage หรือ heal ซึ่งย่อไว้ไม่ได้แสดง 2) Abstraction — trait Item คล้าย interface ของ Go และ Java บอกแค่ว่า “ของที่เป็นไอเทมต้องมี use_on()” ไม่บอกว่าข้างในทำอะไร 3) Composition แทน Inheritance — Rust ไม่มี extends เหมือน Go: Memosprite มี Health เป็นชิ้นส่วนข้างใน จึงมี HP โดยไม่ต้องลากช่อง Light Cone, Relic, Eidolon ของตัวละครมาด้วย (เรื่องกล้วยกับกอริลลาในสไลด์ราคาของ OOP) memosprite คือร่างที่ตัวละครสาย Remembrance เรียกออกมาสู้ มี HP ของตัวเองและโดนศัตรูตีได้ 4) Polymorphism — ต่างจาก Go ตรงที่ Rust ต้องประกาศให้ชัดว่า impl Item for Food ส่วนคลังไอเทมคือ Vec> ใส่ไอเทมต่างชนิดรวมกันได้ แล้วลูปเรียก it.use_on(&mut me) กับทุกชิ้น (&mut me คือขอสิทธิ์แก้ตัวละครตัวนี้ ซึ่ง Rust ยอมให้มีได้ทีละคน สไลด์ ownership ถัดไปจะเล่าต่อ) Rust เป็น OOP ไหม? หนังสือ The Rust Programming Language บท Object-Oriented Programming Features ตอบว่าขึ้นกับนิยาม: Rust มี object ที่รวมข้อมูลกับเมธอด มี encapsulation และ polymorphism ผ่าน trait แต่ไม่มี inheritance ส่วน FAQ ของ Go ก็ตอบคำถามเดียวกันว่า “Yes and no” ประโยคปิด: Go กับ Rust มาคนละทาง แต่ได้ข้อสรุปเดียวกัน คือเก็บข้อดีของ OOP (ซ่อนข้อมูล สัญญา และ polymorphism) แล้วทิ้งการสืบทอด หมายเหตุโค้ด: โค้ดนี้ compile และรันได้จริงบน Rust edition 2021 (Ally, heal และ inventory ย่อไว้) ส่วน trait Item กับ Food ฉบับเต็มอยู่ในไฟล์ hsr.rs ของชุดโค้ด HSR
