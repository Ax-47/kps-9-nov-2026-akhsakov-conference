เปิดยุคที่ 2: ยุคพีซีกับ OOP (ตามหัวข้อ “1980s to 2000s” ของ Wikipedia ซึ่งเล่าเรื่องอินเทอร์เน็ตไว้ในช่วงนี้ด้วย แต่วันนี้เน้นแค่ paradigm จึงข้ามไป) ปัญหา: ซอฟต์แวร์ใหญ่ขึ้นเป็นแสนบรรทัด ทำกันเป็นทีมใหญ่ ข้อมูลที่เป็นตัวแปรกลางถูกแก้จากทุกไฟล์ แต่ละทีมคิดกฎไม่ตรงกัน (เดี๋ยวจะเห็นเป็นบั๊กตัวละครอมตะในเกม Honkai: Star Rail) ทางแก้: รวมข้อมูลกับเมธอดที่คุมกฎไว้ด้วยกันเป็น class แล้วซ่อนข้อมูลไว้ ไอเดียนี้มีตั้งแต่ Simula (1967) และ Smalltalk ที่ Xerox PARC ยุค 70s แต่ดังเป็นวงกว้างตอน C++ ของ Bjarne Stroustrup ที่ Bell Labs ออกขายปี 1985 โค้ดบนสติกเกอร์: ใน C++ สมาชิกของ class เป็น private ตั้งแต่ต้น ไฟล์อื่นจึงแก้ hp ตรง ๆ ไม่ได้ ต้องผ่าน takeDamage ราคาที่จ่าย: ถ้าใช้การสืบทอดมากเกินไป ต้นไม้คลาสจะลึกจนแก้ยาก (สไลด์ราคาของ OOP) สไลด์ถัดไป: เกม Honkai: Star Rail ที่ข้อมูลพันกัน บริบทจาก Wikipedia: ยุค 80s คอมพิวเตอร์ส่วนบุคคลเปลี่ยนวิธีใช้ภาษาโปรแกรม C++ ต่อยอดจาก C ด้วย class และการสืบทอด ส่วน Ada และภาษาอื่นเพิ่มการทำงานพร้อมกัน Wikipedia ระบุว่า Simula ซึ่งเป็นลูกหลานของ ALGOL คือภาษา object-oriented ภาษาแรก (แถว FIX จึงไล่ Simula → Smalltalk → C++) อ้างอิงลำดับยุค: Wikipedia — Programming language (หัวข้อ History)
