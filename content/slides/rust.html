Rust · 2015

Rust: เร็วแบบ C และปลอดภัยกว่า

เริ่มปี 2006 โดย Graydon Hoare · Mozilla สนับสนุนตั้งแต่ 2009 · 1.0 ปี 2015

ปัญหา

  • อยากเร็วแบบ C/C++ แต่ไม่เอาบั๊กหน่วยความจำ
  • ไม่อยากมี GC มาหยุดโปรแกรม

ทางแก้

  • ownership + borrowing: ทุกค่ามีเจ้าของ
  • compiler ตรวจก่อน มีโอกาสพัง = ไม่ให้ผ่าน

ยังเห็นวันนี้

  • Linux kernel: รับเข้า v6.1 (2022) เลิกสถานะทดลอง ธ.ค. 2025
  • Firefox, Android และบางส่วนของ Windows

Stack Overflow Developer Survey: Rust ได้อันดับ 1 ภาษาที่ผู้ใช้อยากใช้ต่อ (most admired) ต่อเนื่องหลายปี

Rust คือคำตอบของปมจากสไลด์ c-cost โดยตรง: อยากได้ความเร็วแบบ C แต่ไม่อยากเจอบั๊กหน่วยความจำ และไม่อยากใช้ GC แบบ Java เกร็ดที่เล่ากันบ่อย: Graydon Hoare เริ่มคิดภาษานี้หลังเจอลิฟต์ในตึกที่พักพังเพราะซอฟต์แวร์ crash (เล่าเป็นเรื่องเล่า ไม่ต้องยืนยันว่าจริง 100%) วิธีของ Rust: ทุกค่าในโปรแกรมมีเจ้าของ (owner) คนเดียว ใครจะใช้ต้อง “ยืม” ตามกฎ และ compiler ตรวจกฎทั้งหมดก่อนรัน ถ้าผิดกฎ = compile ไม่ผ่าน บั๊กแบบ use-after-free จาก c-cost จึงหลุดไปไม่ได้ ของจริงตอนนี้: Linux รับ Rust เข้า kernel ตั้งแต่เวอร์ชัน 6.1 (ปี 2022) และในงาน Maintainers Summit เดือนธันวาคม 2025 ประกาศว่าเลิกเป็น “การทดลอง” แล้ว Rust อยู่ใน kernel ถาวร / Microsoft กับ Google ก็เขียนส่วนใหม่ของ Windows และ Android ด้วย Rust ใน Stack Overflow Developer Survey Rust ได้ most admired (ใช้แล้วอยากใช้ต่อ) มาหลายปีติด ราคาที่จ่ายอยู่สไลด์หน้า
