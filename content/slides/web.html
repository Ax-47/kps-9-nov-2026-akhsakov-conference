01

HTML + CSS

โครงสร้างหน้าเว็บ และการจัดหน้าตา

02

JavaScript

ทำให้ปุ่มกดได้ ข้อมูลบนหน้าเปลี่ยนได้

03

TypeScript + Framework

React, Vue หรือ Svelte ช่วยจัดเว็บที่ใหญ่ขึ้น

04

Backend + Database

Python, Go หรือ Node.js กับ SQL สำหรับเก็บข้อมูล

05

Deploy

เอาขึ้นอินเทอร์เน็ต ให้คนอื่นเปิดได้

โปรเจกต์แรกที่แนะนำ

  1. หน้าเว็บแนะนำตัวเอง
  2. to-do list ที่ปิดเว็บแล้ว ข้อมูลไม่หาย
  3. เว็บที่เพื่อนในห้องใช้จริง เช่น ตารางเวร โหวตเมนู

เริ่มจาก HTML/CSS/JS ล้วน ๆ ก่อน แล้วค่อยไป framework

สายเว็บเริ่มง่ายที่สุด เพราะมีเบราว์เซอร์อยู่แล้ว ลำดับ 5 ขั้นนี้ไม่ต้องเป๊ะ แต่อย่าข้ามขั้น 1–2 ไปเล่น framework เลย เพราะจะไม่เข้าใจว่า framework ทำอะไรให้ TypeScript คือ JavaScript ที่มีชนิดข้อมูล ช่วยจับบั๊กก่อนรัน (นึกถึงบทเรียน Part 1: เพิ่มความปลอดภัย แลกกับต้องเขียนมากขึ้นนิดหน่อย) โปรเจกต์ที่ 3 สำคัญที่สุด: พอมีคนใช้จริง จะเจอปัญหาจริง เช่น เพื่อนกดพร้อมกัน ข้อมูลหาย มือถือแสดงผลเพี้ยน ซึ่งสอนมากกว่า tutorial ทุกตัว
