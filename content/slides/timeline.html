Dijkstra: เลิกใช้ GOTO

ภาพรวมก่อนลงรายละเอียด ใช้เวลา 3–5 นาที ไม่ต้องอ่านทุกกล่อง วิธีอ่าน: แกนกลางคือปี ลูกศรของแต่ละกล่องชี้ไปที่ปีที่ภาษานั้นเปิดตัวครั้งแรก กล่องทึบสีฟ้า (เหมือนป้าย “เล่าในวันนี้”) คือภาษาที่วันนี้จะเล่าละเอียด (FORTRAN, Simula, C, C++, Java, Go, Rust) ส่วนกล่องสีน้ำเงินสด (Dijkstra) ไม่ใช่ภาษา แต่เป็นเหตุการณ์สำคัญ แถบด้านบนแบ่งเป็น 4 ยุคตามหัวข้อย่อยของ History ใน Wikipedia คือ Early developments / 1960s and 1970s / 1980s to 2000s / 2000s to present แต่ละยุคบอกว่าเจ็บเรื่องอะไร แล้วแก้ยังไง ให้ไล่จากซ้ายไปขวาแบบเล่าเรื่องต่อกัน: ยุค Early developments (1940s–50s) โค้ดเป็นเลขล้วน จึงเกิดภาษาระดับสูงอย่าง FORTRAN (ชื่อมาจาก FORmula TRANslation) แต่ยุคนั้นยังกระโดดไปมาด้วย GOTO → ยุคเมนเฟรม (1960s–70s) โปรแกรมใหญ่ขึ้นจน GOTO พันกัน จึงเกิด structured programming ที่ใช้ if / loop / ฟังก์ชันแทน → ยุคพีซี (1980s–2000s) โปรแกรมใหญ่จนข้อมูลพันกันทั้งโปรแกรม (เรื่อง hp ในเกม Honkai: Star Rail) จึงให้ข้อมูลมีเจ้าของผ่าน class แบบ OOP โดย Simula คิดไว้ตั้งแต่ 1967 แต่มาฮิตจริงยุค C++ → ยุค Composition over Inheritance (2000s ถึงปัจจุบัน) ต้นไม้คลาสลึกจนแก้คลาสแม่ทีเดียวลูกหลานพัง ภาษารุ่นใหม่อย่าง Go และ Rust จึงตัด class inheritance ทิ้ง ใช้ struct + interface/trait แล้วประกอบชิ้นส่วนแทน (composition) เส้นแบ่งยุคใช้ตาม Wikipedia ซึ่งเป็นการแบ่งคร่าว ๆ ไม่ใช่ปีตายตัว (เช่น Simula ปี 1967 อยู่ในแถบยุคเมนเฟรม แต่เป็นต้นกำเนิดของ OOP และหัวข้อของ Wikipedia เองก็ซ้อนกันที่ยุค 2000s) Wikipedia เล่าเรื่องอินเทอร์เน็ตกับ Java ไว้ในช่วง 1980s to 2000s ด้วย แต่วันนี้เน้นแค่ paradigm จึงข้ามไป และสังเกตว่าทางแก้ของยุคหนึ่ง มักกลายเป็นปัญหาของยุคถัดไป จุดที่น่าชี้ให้น้องดู: • ยุค 50s — FLOW-MATIC ของ Grace Hopper เป็นต้นแบบของ COBOL ที่ยังรันในระบบธนาคารบางแห่งถึงทุกวันนี้ • ปี 1968 — Dijkstra เขียนจดหมาย Go To Statement Considered Harmful เป็นจุดเริ่มของ structured programming ปูไปสไลด์ถัดไปที่เล่าเรื่อง GOTO • ปี 1970 — Pascal ของ Niklaus Wirth ออกแบบมาเพื่อสอน structured programming โดยตรง (2 ปีหลังจดหมายของ Dijkstra) และเป็นภาษาที่ใช้สอนในมหาวิทยาลัยอยู่หลายสิบปี • ปี 1995 — Java, JavaScript, PHP เกิดในปีเดียวกัน เพราะอินเทอร์เน็ตเพิ่งบูม ทุกคนอยากทำเว็บ • TypeScript — จะกลับมาเจออีกทีใน Part 2 ตอนพูดถึงสายเว็บ ประโยคปิดสไลด์: สังเกตว่าทุกภาษาใหม่ เกิดจากความเจ็บปวดของภาษาก่อนหน้า เดี๋ยวเราจะไล่ดูทีละช่วง หมายเหตุปี: Go ประกาศเปิดตัวปี 2009 (1.0 ปี 2012) ส่วน Rust เริ่มปี 2006 ประกาศต่อสาธารณะปี 2010 แต่ 1.0 ออกปี 2015 จึงใช้ปี 2015 ให้ตรงกับสไลด์อื่น (เป็นกล่องเดียวที่ไม่ใช่ปีเปิดตัวครั้งแรก) / FLOW-MATIC ใช้ปี 1955 ที่เริ่มพัฒนา (compiler ออกให้ใช้จริงต้นปี 1958)
