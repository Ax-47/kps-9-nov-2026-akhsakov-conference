C · 1972

C: ภาษาที่สร้างมาเพื่อเขียน Unix

Dennis Ritchie ที่ Bell Labs · ปี 1973 เขียนเคอร์เนล Unix ใหม่ด้วย C

ปัญหา

  • ระบบปฏิบัติการ เขียนด้วย assembly
  • assembly ผูกกับเครื่อง รุ่นเดียว ย้ายเครื่อง = เขียนใหม่หมด

ทางแก้

  • ภาษาระดับสูง พออ่านรู้เรื่อง แต่ใกล้ฮาร์ดแวร์ พอเขียน OS ได้
  • ย้ายเครื่อง แค่ compile ใหม่

ยังเห็นวันนี้

  • Linux และแกนของ Windows
  • เฟิร์มแวร์ ในเครื่องใช้ไฟฟ้า
  • syntax ที่ C++ Java Go Rust ยืมไปใช้
สไลด์ภาษาทุกหน้าจะใช้ 3 ช่องนี้เหมือนกัน: ปัญหา / ทางแก้ / ยังเห็นวันนี้ ให้น้องจับ pattern ได้ เรื่องเล่า: ยุคนั้นระบบปฏิบัติการเขียนด้วย assembly ซึ่งเป็นคำสั่งของ CPU รุ่นนั้นตรง ๆ พอซื้อเครื่องใหม่ต่างรุ่น ต้องเขียน OS ใหม่ทั้งหมด Dennis Ritchie กับ Ken Thompson ที่ Bell Labs ทำ Unix และ Ritchie สร้างภาษา C ขึ้นมา (ต่อยอดจากภาษา B ของ Thompson) แล้วเขียน Unix ใหม่ด้วย C ทำให้ย้าย Unix ไปเครื่องอื่นได้ด้วยการ compile ใหม่ ทุกวันนี้: Linux เขียนด้วย C เป็นหลัก มือถือ Android ทุกเครื่องรันบน Linux kernel และเฟิร์มแวร์ในไมโครเวฟ เครื่องซักผ้า ส่วนใหญ่ก็ C ฝากไว้: Ken Thompson จะกลับมาอีกทีตอนเล่าเรื่องภาษา Go
