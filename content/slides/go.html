Go · 2009

Go: ภาษาเรียบ ๆ สำหรับระบบใหญ่

Robert Griesemer, Rob Pike และ Ken Thompson (คนร่วมสร้าง Unix) ที่ Google

ปัญหา

  • โค้ด C++ ที่ Google ใหญ่ จน compile นานมาก
  • เซิร์ฟเวอร์ ต้องรับงานพร้อมกัน จำนวนมหาศาล

ทางแก้

  • ภาษาเล็ก กฎน้อย compile เร็ว
  • goroutine + channel ทำงานพร้อมกันง่าย
  • ได้ไฟล์เดียว เอาไปรันได้เลย

ยังเห็นวันนี้

  • Docker และ Kubernetes
  • backend และระบบ cloud
จำ Ken Thompson ได้ไหม? คนร่วมสร้าง Unix จากสไลด์ภาษา C ผ่านไป 40 ปี เขามาร่วมออกแบบภาษาใหม่ที่ Google ปัญหาของ Google ยุคนั้น: โค้ด C++ ใหญ่มาก build ทีรอนาน คนเป็นพันคนต้องอ่านโค้ดกันเอง และเซิร์ฟเวอร์ต้องรับคำขอพร้อมกันจำนวนมหาศาล ทางแก้ของ Go คือ “จงใจให้ภาษาเล็ก” กฎน้อย ใครอ่านโค้ดใครก็เข้าใจ compile เร็ว และมี goroutine ซึ่งเป็นงานย่อยที่เบามาก สร้างเป็นหมื่นตัวก็ได้ คุยกันผ่าน channel ราคาที่จ่าย: เพราะจงใจเรียบ ฟีเจอร์บางอย่างมาช้า เช่น generics เพิ่งเข้ามาใน Go 1.18 ปี 2022 และต้องเขียนเช็ก error ซ้ำ ๆ (if err != nil) จนเป็นมุก / ยังใช้ GC ของที่น้องรู้จัก: Docker กับ Kubernetes ที่ใช้รันเว็บใหญ่ ๆ ทั่วโลก เขียนด้วย Go
