ตอบปมจากเกม Honkai: Star Rail ของเรา: OOP บอกว่า “ให้ข้อมูลอยู่กับคนที่รับผิดชอบมัน” hp ย้ายไปอยู่ใน object Ally และแก้ได้ผ่านคำสั่งของ Ally เท่านั้น ไม่ว่าในเกมจะมีกี่ร้อยไฟล์ที่อยากลดเลือด ก็ต้องผ่านประตูเดียวกันคือ takeDamage() ซึ่งเป็นที่เดียวที่กันไม่ให้เลือดติดลบ เล่าที่มา 3 ช่วง: • Simula 67 — นักวิจัยนอร์เวย์อยากจำลองระบบจริง เช่น คิวรถ หรือเรือในท่า เลยคิดว่าโปรแกรมควรประกอบด้วย “สิ่งของ” ที่มีข้อมูลและพฤติกรรมของตัวเอง • Smalltalk — Alan Kay ที่ Xerox PARC (ที่เดียวกับที่คิดหน้าจอแบบมีหน้าต่างและเมาส์ยุคแรก ๆ) ผลักไอเดียนี้ไปสุดทาง ทุกอย่างเป็น object • C++ — Stroustrup อยากได้ทั้งความเร็วของ C และการจัดระเบียบของ Simula เลยเอามารวมกัน ทำให้ OOP กลายเป็นกระแสหลักในยุค 80–90 น้องที่เคยเขียน class ใน Python หรือ Java คือได้มรดกจากตรงนี้
