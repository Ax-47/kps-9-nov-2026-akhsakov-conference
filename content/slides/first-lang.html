เลือกหนึ่งภาษา แล้วอยู่กับมันให้ได้ 3 เดือน — ภาษาที่สองจะง่ายขึ้นมาก

คำถามยอดฮิตของน้อง: “ควรเริ่มภาษาอะไร” ตอบด้วยคำถามกลับ: “อยากทำอะไร” • Python — เหมาะที่สุดถ้าเริ่มจากศูนย์ เพราะ syntax ไม่ขวางทาง ได้ฝึกคิดเป็นขั้นตอน • C/C++ — ถ้าอยากไปสายแข่ง (สอวน. ส่วนใหญ่ใช้ C/C++) หรืออยากเข้าใจหน่วยความจำจริง ๆ ซึ่งจะทำให้เข้าใจทุกภาษาที่ตามมา • JavaScript — ถ้าอยากเห็นผลบนหน้าจอเร็ว ๆ เปิดเบราว์เซอร์ก็เขียนได้ ไม่ต้องติดตั้งอะไร ประเด็นสำคัญคือบรรทัดล่าง: อย่ากระโดดเปลี่ยนภาษาทุกสัปดาห์ แนวคิดหลัก (ตัวแปร if loop ฟังก์ชัน โครงสร้างข้อมูล) เหมือนกันทุกภาษา เรียนลึกภาษาเดียวแล้ว ภาษาที่สองใช้เวลาไม่กี่สัปดาห์
