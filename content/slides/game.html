เข้าใจ game loop

02

เริ่มเล็ก

Scratch หรือ Pygame ทำเกมจอเดียวให้จบ

03

เลือก engine

Godot (ฟรี โอเพนซอร์ส ภาษา GDScript คล้าย Python) · Unity (C#) · Unreal (C++)

04

ทำให้ “รู้สึกดี”

เสียง เอฟเฟกต์ และความยากที่พอดี

05

Game jam

สร้างเกมให้จบในเวลาจำกัด เช่น 48 ชั่วโมง กับเพื่อน

โปรเจกต์แรกที่แนะนำ

  1. Pong
  2. Flappy Bird ฉบับของเรา
  3. platformer 1 ด่าน

ชอบ Rust: ลอง engine ชื่อ Bevy

หัวใจของทุกเกมคือ game loop: ทุกเฟรม เกมจะ 1) อ่านว่าผู้เล่นกดอะไร 2) อัปเดตตำแหน่ง คะแนน การชน 3) วาดภาพใหม่ วนแบบนี้ราว 60 ครั้งต่อวินาที เข้าใจตรงนี้แล้ว engine ไหนก็ไม่งง แนะนำให้เริ่มที่ Godot: ฟรี โอเพนซอร์ส ไฟล์เล็ก และ GDScript หน้าตาคล้าย Python / Unity ใช้ C# มีคลิปสอนเยอะมาก / Unreal ภาพสวยที่สุดแต่หนักและเรียนยากกว่า อย่าเริ่มด้วย “เกม open world แบบ GTA” — เริ่มจากโคลนเกมง่าย ๆ ให้จบก่อน Pong สอนเรื่องการชน Flappy Bird สอนเรื่องแรงโน้มถ่วงกับการสุ่ม platformer สอนเรื่องฟิสิกส์และการออกแบบด่าน Game jam: งานที่ให้สร้างเกมตามธีมในเวลาจำกัด ได้เพื่อน ได้ portfolio และบังคับให้ทำให้จบ
