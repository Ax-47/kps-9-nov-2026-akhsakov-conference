ทุกสายต้องมี

เครื่องมือ 5 อย่างที่ต้องใช้ให้เป็น

Editor (VS Code)

เขียนโค้ด มีตัวช่วยเติมคำ และเตือน error ทันที

Terminal

สั่งรัน compile ย้ายไฟล์ด้วยคำสั่ง ไม่ต้องคลิก

Git + GitHub

เก็บประวัติทุกเวอร์ชัน และเป็น portfolio ให้คนอื่นเห็นงาน

อ่าน error + docs

error บอกบรรทัดและสาเหตุ อ่านให้จบก่อนไปค้นในเน็ต

AI เป็นติวเตอร์

ถาม “ทำไม” ไม่ใช่ “เขียนให้หน่อย” ไม่งั้นสมองไม่ได้ฝึก

เครื่องมือที่ทุกสายใช้เหมือนกัน ฝึกตั้งแต่เนิ่น ๆ คุ้มมาก • Editor — VS Code ฟรี ใช้ได้ทุกภาษา • Terminal — ตอนแรกน่ากลัว แต่จำได้แค่ cd, ls, แล้วก็คำสั่งรันโปรแกรม ก็ใช้ได้แล้ว • Git + GitHub — เหมือนปุ่ม save ที่ย้อนกลับได้ทุกจุด และ GitHub คือ portfolio ที่ใช้ยื่นค่าย ยื่นมหาลัย หรือฝึกงานได้ • อ่าน error — มือใหม่ส่วนใหญ่เห็น error สีแดงแล้วตกใจ ข้ามไม่อ่าน แต่ error มักบอกชัดว่าบรรทัดไหน ผิดเพราะอะไร • AI — ใช้ได้ และควรใช้ แต่ใช้ถามเหตุผล ให้อธิบาย ให้ใบ้ ไม่ใช่ให้เขียนแทนทั้งหมด เหตุผลทางสมองจะเล่าใน Part 3 (ถ้า AI ทำแทน เราได้แค่ “รู้ว่า” แต่ไม่ได้ “ทำได้”)
