ชื่อเหมาะกับอะไร
programming.in.thโจทย์ภาษาไทย รวมข้อสอบ TOI เก่า
CSES Problem Setโจทย์เรียงตามหัวข้อ ไล่ทีละเรื่องได้
AtCoder Beginner Contestแข่งออนไลน์เกือบทุกสัปดาห์ เหมาะมือใหม่
Codeforcesแข่งออนไลน์บ่อย มี rating วัดพัฒนาการ
USACO Guideแผนเรียนเป็นขั้น พร้อมคำอธิบาย
Competitive Programmer’s Handbookหนังสือฟรีของ Antti Laaksonen
posn.or.thประกาศ หลักสูตร และกำหนดการ สอวน.
แนะนำลำดับการใช้: 1) เริ่มที่ programming.in.th — โจทย์ภาษาไทย อ่านง่าย มีโจทย์ TOI เก่าให้ลองระดับจริง 2) CSES Problem Set — โจทย์เรียงตามหัวข้อ เหมาะกับการไล่ skill tree ทีละกล่อง 3) พอเริ่มคล่อง ลองแข่งออนไลน์ AtCoder Beginner Contest (เหมาะกับมือใหม่ จัดเกือบทุกสัปดาห์) หรือ Codeforces (มี rating ให้เห็นพัฒนาการ) 4) USACO Guide กับ Competitive Programmer’s Handbook (ของ Antti Laaksonen คนเดียวกับที่ทำ CSES) ใช้อ่านทฤษฎีประกอบ 5) เว็บ สอวน. posn.or.th ดูประกาศสอบคัดเลือก หลักสูตร และกำหนดการปีล่าสุด ส่วนใหญ่เป็นภาษาอังกฤษ — เป็นโอกาสฝึกอ่านภาษาอังกฤษเชิงเทคนิคไปด้วย ซึ่งจำเป็นมากในสายนี้ (ถ้ามีกลุ่มติว ชมรม หรือ Discord ของโรงเรียน/ศูนย์ สอวน. ใกล้บ้านน้อง ใส่เพิ่มตรงนี้)
